关于本看板

  1. 定位：本地 / 内网并排看多个 Cursor 账号的用量与花费，不是官方 Team Admin。
  2. 登录：固定账号 admin，默认密码 admin，首次登录必须改密。
  3. 服务配置：改服务器上的 .env（模板 .env.example），改完重启；无网页设置页。
  4. 录入账号：本机导入 / 粘贴 Token；多机用 Reporter 扩展定时上报（显示名默认机器名）。
  5. 刷新：服务端按每个账号的上次更新时间错开刷新（间隔见 AUTO_REFRESH_SEC，默认 1800 秒）；上报后会立刻拉一次用量。列表「更新模型」可强制全量更新。
  6. Token：落盘 JWT 会过期。看板不刷新 Token；本机再导入，或靠扩展在 Cursor 开着时续报。
  7. 面板指标：Total / Cursor Models / Other Models / Grok Bot（详情页），以及 Today · Yesterday · Last 30 Days。
  8. 请求明细：详情页与 官方用量页 同源逐次请求。
