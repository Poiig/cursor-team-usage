关于本看板

  1. 定位：本地 / 内网并排看多个 Cursor 账号的用量与花费，不是官方 Team Admin。
  2. 登录：在登录页进入，或申请注册，管理员在「用户」页同意后即可登录。禁用后立即失去访问。
  3. 权限：普通用户可看全部用量、刷新、一键切换；添加 / 删除账号、导出、用户管理、报表中心仅管理员。异常账号（同步失败）不可切换。
  4. 一键切换：账号卡片点「切换」→ 优先通知本机扩展桥 127.0.0.1:3781（Agent 模式可用）→ Cursor 弹窗确认后先备份当前本机登录态，再写入目标账号并重启。可用列表「恢复上次账号」或命令面板「恢复上次账号」从备份区还原。桥不可用时回退 cursor://，或「粘贴切换票据」。
  5. 服务配置：改服务器上的 .env（模板 .env.example），改完重启；无网页设置页。
  6. 录入账号：本机导入 / 粘贴 Token；多机用 Reporter 扩展定时上报（显示名默认机器名）。
  7. 插件安装：登录后在账号页点「安装插件」。安装包绑定当前用户并写入签名；用户页能看到版本。地址只认 PUBLIC_BASE_URL。优先本机桥 :3781，否则复制 PowerShell 一行命令。扩展启动会检查更新。
  8. 刷新：服务端按每个账号的上次更新时间错开刷新（间隔见 AUTO_REFRESH_SEC，默认 900 秒）；上报后会立刻拉一次用量。列表「刷新用量」会从最久未更新的账号开始逐个刷新。
  9. Token：落盘 JWT 会过期。看板不刷新 Token；靠扩展在 Cursor 开着时续报。关掉 IDE 即停止上报。换号后再登录旧号时，旧会话可能被 Cursor 注销。
